# Домашнее задание №3 — Incident Radar

Incident Radar — консольная утилита на Go для анализа журналов доступа NGINX. [Описание задания](TASK.md)

## Возможности

- Читает локальные файлы, раскрывает glob-маски и загружает логи по HTTP и HTTPS.
- Разбирает логи построчно, пропускает некорректные записи и фильтрует запросы по датам.
- Собирает статистику по кодам ответа, популярным ресурсам и размерам ответов.
- Сохраняет отчёты в JSON или Markdown с защитой от перезаписи. При успехе возвращает код `0`, при внутренней ошибке — `1`, при ошибке параметров или источника — `2`.

## Запуск

Эта команда создаёт JSON-отчёт по локальному логу из проекта.

```sh
make run ARGS='--path sample_logs/access.txt --output report.json'
```

Для отчёта по HTTP запусти `make serve` и выполни команду ниже в другом терминале.

```sh
make run ARGS='--path http://127.0.0.1:8000/access.txt --format markdown --output report.md'
```

## Инструменты и тесты

Использовал Go и стандартную библиотеку для CLI, чтения файлов и HTTP, разбора логов и формирования отчётов. Для тестов использовал `testing` и `httptest`, для статического анализа — golangci-lint. Команды собраны в Makefile, автоматические проверки настроены в GitLab CI.

`make test` запускает тесты и формирует HTML-отчёт о покрытии.
